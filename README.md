# SuperCalculator
The Calculator that can be used by anyone and anyone.
SuperCalculator does simple things and is programmed in Python.

This is very easy to use as all you need is Python insstalled on your computer.
This does not use any libraries and use fresh Python command prompt.

This is a very portable file and does not require any assets/content folder, you can turn this into a executable to pin it to your taskbar if you are using Windows. You can give it a logo/icon as there isn't actually one for this.

Recommendation!
1: Use the stable release of python.
2: Put this on your desktop if you are gonna use this often.
